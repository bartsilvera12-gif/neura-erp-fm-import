# FM Importados

Tienda de perfumes y cosméticos, venta mayorista y minorista. El proyecto tiene dos partes:

- **Web:** multipágina y sin pasarela de pago. Las compras se cierran por WhatsApp y redes.
- **ERP:** retail. Módulos: Dashboard, Caja, Inventario, Gastos, Compras, Reportes, Presupuestos y Clientes.

## Contenido

- `prototipo/`: diseño original exportado de Claude Design (`FM Importados.dc.html` es la versión vigente, `v1` es la anterior).
